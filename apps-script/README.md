# 商品リスト共有バックエンドのセットアップ

B払い計算ツールの商品リストを複数人・複数端末で共有するための、Googleスプレッドシートを使った無料バックエンドです。料金プラン自体が存在しないため、課金の心配はありません。

## 手順

1. **Googleスプレッドシートを新規作成**します（[sheets.new](https://sheets.new)）。名前は自由（例:「B払いツール商品リスト」）。

2. シート下部のタブ名を **`products`** に変更します（デフォルトの「シート1」をダブルクリックしてリネーム）。

3. メニューの **拡張機能 > Apps Script** を開きます。

4. デフォルトで入っているコード（`myFunction` など）を全て削除し、このフォルダの [Code.gs](Code.gs) の中身を貼り付けます。

5. コード内の

   ```js
   const API_TOKEN = "REPLACE_WITH_YOUR_OWN_SECRET";
   ```

   の部分を、他人に推測されない自分だけの文字列に変更します（第三者が商品リストを書き換えられないようにするための簡易パスワードです）。

6. 上部の保存アイコン（フロッピーディスクの絵）で保存します。

7. 右上の **「デプロイ」→「新しいデプロイ」** をクリックします。

8. 歯車アイコンから種類を **「ウェブアプリ」** を選択します。

9. 以下のように設定します。
   - 説明: 任意（例: v1）
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**

10. **「デプロイ」** をクリックします。初回はGoogleの権限確認画面が出るので、自分のアカウントを選び「詳細」→「(プロジェクト名)に移動」→「許可」と進んでください。

11. 発行された **ウェブアプリのURL**（`https://script.google.com/macros/s/xxxxx/exec` の形式）をコピーします。

12. コピーした **URL** と、手順5で決めた **APIトークン（秘密の文字列）** の2つを教えてください。この2つを使って、ツール本体（index.html）を商品リスト共有対応に更新します。

## 補足

- 商品リストの書き込み（追加・編集・削除の保存）にはAPIトークンが必要です。閲覧（読み込み）のみは誰でも可能です。
- スプレッドシートを直接開いて `products` シートを見れば、現在の商品リストをいつでも確認・手動編集もできます（ただし手動編集した場合、次にツール側から保存すると上書きされる点に注意してください）。
- コードを変更した場合は、再度「デプロイ」→「デプロイを管理」→ 該当のデプロイの鉛筆アイコン →「新バージョン」を選んで再デプロイしてください（URLは変わりません）。
